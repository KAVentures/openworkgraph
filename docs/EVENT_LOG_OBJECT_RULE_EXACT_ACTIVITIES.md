# Exact activities in object-centric rules

Object rule activity suggestions come from the displayed object graph, which can omit less frequent event types. Enter an exact stored label for activity A, activity B or the optional linking activity to override its suggestion. Values preserve spaces, punctuation and Unicode, and labels longer than 200 Unicode characters are refused. Choosing another suggestion clears that field's exact entry.

Object rules evaluate the original retained event labels across the whole log. They do not apply the main case filter, activity mapping or hidden-activity filter. The rule result reports whether an entered activity exists in the retained log; a missing activity and a vacuous result do not establish business compliance or source completeness. Resource or person identity is not inferred.
