# CSV resource presence in saved event logs (#326 R6)

A CSV event's optional mapped resource is an **identifier**, not a measure of an employee's performance. The bulk DuckDB import now follows the shared streaming CSV reader's resource-presence rule: an empty or Unicode-whitespace-only resource (for the 19 whitespace code points allowed by identifier control-character validation) is stored as the empty string, meaning *resource not supplied*. A nonblank resource retains its exact supplied text, including leading/trailing spaces; no identity matching, case folding or employee inference is performed.

This normalization happens **only at the final bulk INSERT**, after the original value has passed the existing identifier-length and control-character validation. It does not permit tabs, newlines or other forbidden controls, and it does not change the raw uploaded bytes or the `source_sha256` digest. A newly imported log's stored-content digests reflect the normalized resource field. Existing stored logs and their historical quality reports are not rewritten.

The existing counts-only `events_without_resource` diagnostic counts whitespace-only resources imported through this CSV path as missing. The fast CSV importer, shared streaming reader and current diagnostics share one permitted-whitespace character set; non-ASCII blanks such as nonbreaking, em, narrow no-break and ideographic spaces are no longer stored as supplied resource IDs. The disallowed control whitespace (including tabs, line feeds and U+0085) remains rejected before normalization. The field name, REST/MCP/dashboard contracts, permissions, local-only consent, tenant isolation and deletion behavior remain unchanged. These counts describe only supplied rows, not source-system completeness or a verified staffing assignment.

Synthetic regressions compare the bulk import with the shared streaming CSV reader for all 19 permitted whitespace characters, check exact preservation of padded nonblank resource labels, source-byte and stored-content digest consistency, and verify that quoted tab/C1-control-containing resources remain rejected. This does not establish real-provider or customer acceptance.
