# Cross-log domain-pack benchmarking (R23/R4)

Use Domain packs → Benchmark an installed pack across retained logs. Install the same version on both logs, map their actual source labels independently, and set identical parameters. Load installed packs, choose another retained log, review both sources, mapping roles, parameters and time coverage, then explicitly compare. The preview fingerprints both current installations and stored events, objects and event-object links. Changed source/configuration refuses comparison until a new preview. No new persistent database or external source connection is used.

Canonical definition indices align metrics and rules even when the two systems use different names. The report includes metric median/p90/mean differences, units and coverage; case-rule activated, decided, violating, unknown and unactivated counts; object-rule denominators and completion; separate object model lifecycle coverage. Unmapped optional roles and incomplete object rules have no comparison delta. A case-rule's uncertainty bounds include unknown activated cases; the lower/upper difference is calculated without assuming paired cases. The observed difference is not a causal estimate. Populations can overlap, be differently sized, and have different source completeness. No ranking, pooled value or compliance claim is made.

The dashboard exports JSON and CSV with exact report digests. No individual case, event or resource identifier is returned by the comparison endpoint. Source labels and local log IDs remain in the explicitly reviewed configuration and exports; this is not an anonymized publication format.

Local dashboard-session-only POST /v1/event-logs/{log_id}/domain-packs/{pack_id}/benchmark/preview accepts other_log_id. POST the same path without /preview with other_log_id and expected_preflight_sha256. Requests are strict; different pack versions or parameters prevent comparison. Applied activity mappings, hidden activities and supplied relationship rules are refused to keep the comparison and source-fingerprint scope consistent. Limits: 500k combined source rows (events, objects, event-object links), 100 definitions, one concurrent comparison. Tests use real retained CSV logs with renamed equivalent source roles and independently verify the stale-source and omission behavior. Customer/source-system acceptance remains outstanding.

Additional coverage includes renamed object-centric order-to-cash sources, exact reference model counts, dashboard-only HTTP access, stale preflight rejection and bounded request bodies. Preview and comparison share the single-operation admission guard.
