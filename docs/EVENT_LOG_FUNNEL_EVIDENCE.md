# Milestone funnel case evidence

After choosing a funnel, select a milestone and either **Reached step** or **Stopped before step** to inspect the matching cases. The dashboard shows up to 50 case keys at a time in literal key order. Use **Next cases** and **Previous cases** to browse, and **Open case** to inspect its retained event history. The same case notion, funnel steps, conversion window and case filter apply to each page. Changing those controls requires running the funnel again.

The dashboard-session-only funnel endpoint accepts `evidence_page=true`. Its first response includes an evidence `revision` and `next_after` cursor. Later requests supply both `evidence_after` and `evidence_revision`; a mismatch requires rerunning the funnel. The revision covers the funnel settings and the ordered matching case keys, last activities and steps reached. It protects the displayed evidence list from mixing changed results; it is not a hash of all event details or a guarantee of source completeness. Each page recomputes the funnel over the selected local log, so large logs can take time to page through. Existing requests without `evidence_page` retain their original first-50 response.
