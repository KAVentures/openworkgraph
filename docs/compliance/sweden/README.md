# Swedish / EU deployment pack

These templates are implementation aids for organizations considering OpenWorkGraph in Sweden or the EU. They are **not legal advice** and do not determine the lawful basis, proportionality, collective-bargaining duties, or controller/processor roles for a particular deployment. The deploying organization should involve its data-protection officer/privacy counsel and, where relevant, worker representatives before rollout.

OpenWorkGraph is designed to support a privacy-minimizing deployment: local-first capture, no typed text, no clipboard contents, no ordinary key identities, no screenshot bytes in the Gateway contract, configurable retention/deletion, and the ability to prefer aggregate/process-level analysis over individual traces. Those technical properties do not by themselves make a deployment GDPR-compliant.
