- timestamps and work-session/device identifiers;
- application, window, browser page/surface context;
- event/action type and timing;
- interaction counts and safe control/UI labels;
- copy/cut/paste occurrence and transfer linkage without clipboard contents.

The standard Gateway path does **not** send typed text, clipboard contents, ordinary key identities or screenshot bytes.
