# Exact outcome activity for open-case predictions

For **Case will include activity**, the activity list suggests up to 500 frequent labels. Enter an exact outcome activity or use **Find labels** to search the current case notion, including labels outside that list. Exact labels preserve spaces and Unicode; an unknown label is not silently replaced by a suggestion. Choosing a different suggestion clears the exact entry.

The selected activity is used consistently for the live prediction, the quality monitor and newly saved prediction snapshots. Editing it clears the live prediction and monitoring results. These are estimates from observed cases, not verified outcomes or commitments.
