# Navigate to an exact path activity

The path explorer displays up to 30 of the most common next activities. To follow an omitted branch, enter its literal label in **Exact next activity** or use **Find labels**, then choose **Go to exact activity**. Search covers the current case notion, and the path itself still respects the active case filter. A label that does not continue the current path yields zero matching cases; it is not evidence of an observed branch. Leading and trailing spaces, commas and Unicode are preserved.

The existing start and anywhere anchor semantics apply, as does the 30-activity path limit. Use **Back one step** or **Explore from the start** to change the path. The search does not expose or modify event data beyond existing dashboard authorization.
