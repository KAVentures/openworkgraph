# Map labels beyond the suggestion list

Domain-pack setup suggests the 1,000 most frequent object types and activity
labels from the selected log. To map a label outside that list, choose **Enter
exact label…** for the role and type or paste the label as it appears in the log.
The existing install validation checks exact, case-sensitive membership in the
selected log; an unknown label is refused. Previously saved mappings outside the
suggestions reopen in the exact-label field.

This does not search source systems, send data externally, change the selected
log, or infer label meaning. It retains the existing local storage confirmation,
owner-session access, conditional-save protection and pack assumptions. The user
must know the exact label. The 1,000 suggestions remain bounded; this is not a
complete label browser.
