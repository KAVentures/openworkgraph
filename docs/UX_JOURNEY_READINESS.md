# Guided journey: personal review progress

The dashboard's five-stage guide now includes a **session-only, sequential review checklist**. Open the actual privacy, discovery, process-map and opportunity workspaces; each successful navigation enables its matching acknowledgment. Acknowledgments must be checked in order. Reopening an upstream workspace clears its own and all downstream acknowledgments. Unchecking an earlier step also clears later ones. Reset and reload discard all progress.

After all four acknowledgments, **Open handoff settings after review** navigates to the existing Connect AI workspace. It does not contact a provider, approve an opportunity, grant consent, verify evidence, authorize a tool or execute an agent. Users must separately inspect current process revisions, consent, authorization and action approvals in the authoritative workflows. This feature is a human orientation aid, not a durable audit trail or revision-bound execution gate.

## Acceptance and limitations

Keyboard-operable native buttons and checkboxes, disabled out-of-order checks, live progress status, and reset are provided in the production dashboard. Static regression guards check integration invariants. Native browser, CI, and consenting-user acceptance remain required before declaring this feature fully validated. This does not close roadmap R5's immutable lineage or real-pilot acceptance gaps.
