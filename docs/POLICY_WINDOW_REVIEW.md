# Whole-window policy question review (R11)

Open the existing process clarification panel and prepare an effective-dated
policy timeline against one saved process revision. Expand **Whole-window policy
question review** and run the review. The date/priority declarations and exact
timeline digest are reused; no independent source store is introduced.

Each distinct ordered document bundle is scanned once (at most 12 bundles,
1.2 million scanned characters and 5,000 question-to-interval memberships).
Oversized requests refuse instead of silently sampling. The existing lexical
clarification engine and its bounded scan diagnostics are reused. The output
contains generated question counts for each resolved interval; unresolved gaps
or ambiguous overlaps are not analyzed or bridged.

For each generated question, inspect the number of resolved days on which it
appears, days with incomplete evidence coverage, distinct evidence digests
and exact effective intervals. Adjacent resolved intervals classify new,
no-longer-generated, changed-evidence and same-evidence question IDs. Inspect
an interval or comparison through the existing date review to see exact
citations; the window export contains no source text or citation excerpts.
Changing the prepared timeline invalidates the displayed result.

The report is descriptive, not a reconstruction of past human decisions.
A generated question disappearing does not establish resolution or compliance.
A bounded complete scan does not establish semantic completeness or source
authority. No human ledger decisions are imported, recorded or altered; no
model changes, policy approval or execution authority are granted.
