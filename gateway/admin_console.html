Group invitation

One code for many computers. Each employee types their own identity when joining, so it is not verified: prefer personal invitations on the Employees tab. If your organization requires verified identities, group invitations cannot enroll new computers.

Option A: send employees this join code. They open OpenWorkGraph → Organization → Join your organization, review what is shared and confirm.

Option B: zero-touch via device management. Deploy OpenWorkGraph together with this managed.json to:

  • macOS: /Library/Application Support/OpenWorkGraph/managed.json
  • Windows: C:\ProgramData\OpenWorkGraph\managed.json

On first start the computer joins automatically and its dashboard visibly shows Managed by your organization with what is shared. Identity comes from the OS username; link the computers to employees afterwards.

Treat the join code like a password: it cannot read evidence, but it can enroll computers until it expires, is used up, or is revoked.
