Publish a reviewed snapshot

In the local event-log workspace, run an analysis, select “Prepare sharing snapshot”, review it, then download it. Group codes have meaning only within that file. Numeric values, units and your title may still be sensitive. Every permitted member can read all retained revisions; publishing a new revision does not hide an old one.

Revisions keep the current expiry. Only the owner can renew it under Access.

Access and retention

Members need the corresponding company analysis scope as well as this role. Revocation stops future reads and exports; it cannot recall copies already downloaded. Clearing this list removes all members.
