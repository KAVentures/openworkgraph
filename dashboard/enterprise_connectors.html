Enterprise event feeds

For a customer API that implements OWG's event-feed contract. Configure its exact HTTPS endpoint in the deployment allowlist and supply its read-only bearer in a named environment variable. Nothing is read until separately confirmed. All source event, case and resource identifiers are pseudonymized; activity labels are retained as entered by the source.

Create a feed

Create native Google Workspace audit feed

Connect Google Workspace audit in the main dashboard's Business system sign-in first. The Google Admin SDK Reports API must be enabled for your registered app. This connector reads audit event metadata, not mail, chat or document contents.

Create native SQL event feed

Choose a deployment-approved SQL source. Your administrator defines its exact relation and columns in the local source catalog. No arbitrary SQL, passwords, database paths or connection strings are entered here. PostgreSQL uses a verified TLS connection and read-only snapshot. SQLite reads a strict local table in read-only mode.

Create native Slack feed

Choose either Enterprise Audit Logs (organization-owner user token with auditlogs:read) or one explicitly approved, non-shared channel (member token with the appropriate channel read/history permissions). The deployment provides a dedicated token environment variable. Message content may be returned transiently by Slack's history API; only activity metadata is retained. Direct messages, externally shared channels and thread-reply traversal are excluded.

Create native Salesforce CRM history feed

Use an approved Salesforce API and identity-scoped OAuth sign-in with a read-only integration user. Select tracked field names and optional exact CRM record IDs. This connector requests field-change metadata, not old/new values or record contents. An empty record list requires separate unrestricted-record approval.

Create native ServiceNow operations feed

Choose exact tables, tracked field names, optional creation events and record IDs. The integration account must be configured for UTC. Source reads use fixed Table API projections; field values, descriptions, usernames and approval decisions are not retained. The stricter repeat-read option checks whether the same projected records are returned twice within one bounded window.

Create native SAP procurement feed

Choose a deployment-approved SAP OData V2 source, exact purchase orders and evidence streams. The dates are day-level business dates represented at midnight UTC for storage, not actual execution times. Material and invoice header reads may receive unselected references transiently; only selected purchase-order events are retained.

Native streams

Create native Dynamics 365 / Dataverse audit feed

Choose a deployment-approved Dataverse environment and application user. Select audited tables and operation codes. Only audit metadata is retained, not changed field values or CRM record contents.

Audit operations

Create native HubSpot CRM history feed

Choose a deployment-approved private application, exact CRM record IDs and property names. HubSpot returns property values transiently; only property-change timestamps, activity labels and pseudonymous case identities are retained. The API's returned history is not a complete audit journal.

Create native Databricks SQL warehouse event feed

Choose a deployment-approved event view, not arbitrary SQL. Only reviewed activity labels, exact timestamps and pseudonymous source identities are retained. The source must have STRING IDs and activity columns and a TIMESTAMP column.

Create native Snowflake SQL API event feed

Choose a deployment-approved event view, not arbitrary SQL. Only reviewed activity labels, exact timestamps and pseudonymous source identities are retained. The source must have STRING IDs and activity columns and a TIMESTAMP_LTZ or TIMESTAMP_TZ column.

Create native NetSuite SuiteQL event feed

Choose a deployment-approved curated custom event record, not arbitrary SQL. Only reviewed labels, exact UTC microseconds and pseudonymous identities are retained. The source must have stable internal IDs, immutable case identities and integer UTC epoch microseconds.
