# Workflow Observer Browser Sensor v0.2

Local semantic browser capture for Workflow Observer.

This version is event-driven. It records navigation, tab activation, pointer activation, focus on editable controls, form submissions, control changes, and copy/paste occurrence. It does not record typed values, clipboard contents, password contents, URL query strings, or fragments.

It injects into matching frames so embedded editors/enterprise apps are better covered. If upgrading an unpacked extension, use the browser extension page's **Reload** button after Workflow Observer updates the files.
